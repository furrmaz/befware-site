# befware.com.tr

Befware'in kurumsal sitesi. Tamamen statik (HTML + CSS + birkaç satır JS), GitHub Pages ile yayınlanır.

- `index.html`: tek sayfa site
- `apps/`: uygulama logoları
- `videos/`: tanıtım videoları ve kapak görselleri
- `CNAME`: özel alan adı (befware.com.tr)

Yeni uygulama eklemek için `index.html` içindeki `<article class="app">` bloklarından birini kopyalayın.
